# Fotografii

Adaugă aici fotografii reale (JPG, ~1600px lățime). Site-ul le afișează automat;
până atunci apare un placeholder cu descrierea fotografiei necesare.

- `hero.jpg` – imaginea principală (pui într-o gospodărie rurală), format portret 4:5
- `despre-noi.jpg` – gospodar și pui, 4:3
- `gospodarii/muresan-1.jpg` … `muresan-3.jpg`
- `gospodarii/deal-1.jpg` … `deal-3.jpg`
- `gospodarii/rusu-1.jpg` … `rusu-3.jpg`

Căile sunt definite în `src/data/farms.ts`.
