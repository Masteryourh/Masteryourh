# Room-Based Architecture — proposal 28 Nov 2026
REVIEW ONLY. Founder requests Claude opinion before integration. No implementation authorization.
Source: recovered excerpts of founder conversation Arhitectura baza date - Concept, project PUII MEI; full transcript not available. Founder concept: central archive/registry, information wall, individual rooms/files per user, role magnifier, admin panorama; desktop and mobile remote per role; mobile detailed dashboard query on demand with automatic authorization to reduce data traffic. Earlier Librarian principle: interfaces access authorized projections only.
Reviewed exact chapter 02 and 14 drafts. Both already define scoped DTOs, workspace, IAM, mediator, repositories, private object storage. Proposed extension makes room/projection contract explicit; not a new database per user or physical monolithic file. One canonical domain record; rooms reference authorized data, not copies. Separate person identity, organization/household ownership, membership, assignment, role and device. Multiple roles per person and multiple users per household. Admin panorama scoped, not unrestricted writes. Librarian logical boundary with parallel domain executors, no singleton bottleneck. All server actions/REST/AI through same policy enforcement; no browser DB access.
## Device contract
Admin desktop panorama + mobile operational commands; managers same with territory scope; household app-first and desktop analytics; customer website ordering and optional tracking app with order number+key exchanged for limited session (security review, no secrets in URL/log); courier mobile only. Mobile initial compact task/alert projection; on-demand detail via explicit typed query, automatic server authorization every request, not human approval or remote desktop streaming. Sensitive writes retain approval gates. Cursor, field allowlist, asOf/version, bounded query, conditional refresh; no authenticated persistent cache by default. Measure bytes, p50/p95, query count, freshness and authorization revocation. No promise of savings until benchmark.
